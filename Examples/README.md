# IntuiForge article examples

The example articles are the validated JSON/Markdown fixtures from the implementation kit. They demonstrate scientific explainers, educational lessons, knowledge maps, data explainers, and a temperature visualization. They contain declarative content; the engine validator and renderer provide their behavior.

Use them as content examples, not as a substitute for the public API. Check each example against `@intuiforge/engine/article` before mounting. Preserve stable IDs when adapting the content. The full implementation-kit fixtures remain at `IntuiForge-Implementation-Kit/Examples/` in the source workspace.
