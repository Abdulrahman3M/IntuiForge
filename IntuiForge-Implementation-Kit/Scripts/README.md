# Helper Scripts — Read-Only by Default
`python Scripts/Validate-Kit.py` verifies handoff files, feature mapping and illustrative examples only. `python Scripts/Audit-Zip.py --zip "X:\path\RichViz.zip" --json "Execution-State\zip-audit.json"` records names, sizes and SHA-256, flags traversal/symlinks/excessive expansion; **does not extract**. `python Scripts/Print-Phase-Prompt.py P00` prints a bounded instruction. No helper runs install steps, starts a browser, modifies source code or claims the engine has been implemented. Browser operations must use owner skill, not new competing helper scripts.
