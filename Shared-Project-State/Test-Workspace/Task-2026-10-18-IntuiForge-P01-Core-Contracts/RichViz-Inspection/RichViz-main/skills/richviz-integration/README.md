# Rich Visualization Library Installation Skill

Use `SKILL.md` when installing Rich Viz into a web project for the first time, integrating visualizations, or removing a proven-unused integration. It requires a host audit before edits, local and license-aware dependency reuse, a narrow reversible integration, and focused runtime verification. For updates to an existing installation, use [`../richviz-updater/SKILL.md`](../richviz-updater/SKILL.md).

The repository root contains the canonical API, engine compatibility, asset rights metadata, examples, and scripts referenced by the skill. The [Visual Reference Browser](../../visual-browser/README.md) exposes current examples and stable IDs. Keep references in sync when paths or contracts change.
