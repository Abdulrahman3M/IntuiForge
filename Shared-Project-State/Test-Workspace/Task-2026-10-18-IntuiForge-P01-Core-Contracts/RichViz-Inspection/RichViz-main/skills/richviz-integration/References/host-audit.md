# Host audit checklist

Record evidence for: framework and versions; module/build format; route and deploy base path; CSP directives; local/offline policy; visualization/chart/diagram packages and versions; React runtime ownership; icon/asset systems; CSS tokens; theme and RTL strategy; lazy import and teardown pattern; dependency manager/lockfile; license and vendor notice policy; exact pages/types that need RichViz.

Inspect manifests, lockfiles, entry points, CSP configuration, and directly relevant feature modules only. Expand inspection only when an import, route, or asset reference requires it.
