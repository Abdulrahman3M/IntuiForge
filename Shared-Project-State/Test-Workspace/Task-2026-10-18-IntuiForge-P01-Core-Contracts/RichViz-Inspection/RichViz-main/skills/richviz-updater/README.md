# Rich Viz Updater Skill

Use `SKILL.md` to compare and upgrade an existing Rich Visualization Library installation. It maps upstream files to host paths, preserves local changes, requires a reversible plan, and validates affected runtime behavior before switching versions. Its comparison script is read-only.

For the first installation, use [`../richviz-integration/SKILL.md`](../richviz-integration/SKILL.md). Stable examples and visual IDs are available in [`../../visual-browser/README.md`](../../visual-browser/README.md).
