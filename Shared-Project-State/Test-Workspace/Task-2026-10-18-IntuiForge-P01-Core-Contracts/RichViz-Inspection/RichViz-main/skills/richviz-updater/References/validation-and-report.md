# Validation and update report

Run checks for directly affected imports, paths, schema/API, renderers, engines, assets, RTL/LTR, keyboard/accessibility, responsive layout, consumer integration, build, and licenses as applicable. Exercise changed runtime behavior in the actual host. Record command, scope, and outcome; distinguish not-run checks from passes.

## Update report fields

- Previous and target Rich Viz version/revision and evidence.
- Installed root and upstream-to-host path map.
- Files added, updated, renamed, and removed (each with reason and destination).
- Local customizations preserved or retired (reason and proof); unresolved conflicts/decisions.
- Spec/content migrations and before/after integrity evidence.
- Backup/restore point and rollback procedure.
- Tests run, observed results, tests not run, known risks, final status.
