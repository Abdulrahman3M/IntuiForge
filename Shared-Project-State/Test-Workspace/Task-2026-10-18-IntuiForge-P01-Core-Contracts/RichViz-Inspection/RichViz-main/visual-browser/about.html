About

A visual way to explore Rich Viz.

Why this website exists

This website makes the contents of Rich Viz easy to browse by sight. It lets people inspect rendered examples, icons, standalone SVG artwork, and sticker files without opening source files one by one.

The pages read from the library’s registries and discovered asset folders. The browser is a visual index of the library, not a second place where its examples are authored. As library content changes, the matching page updates from those sources.

Use a visual in your project

Open a gallery item to see its stable reference ID, source path, format, and usage notes. Use the Rich Viz integration guide to add supported visualizations to a host project.
