Rich Visualization Library

Rich Viz is a reusable visual library for articles, documentation, and digital products.

Its validated visualization types, renderers, examples, icons, and licensed asset collections are organized around stable references and source-of-truth registries.

Explore the library

How the project is organized

Core schemas and renderers power diagrams and charts. Independent asset collections preserve their own sources and license notices. The browser presents these real project contents for visual discovery without maintaining a duplicate catalog.
