# حزم تثبيت IntuiForge للوكيل

هذه الحزمة تضم ملفي ZIP منفصلين لإصدار IntuiForge 1.0.0:

1. `IntuiForge-Engine-1.0.0-Offline-Installer.zip` — محرك قابل للتثبيت دون اتصال، manifest وبصمة وتراخيص ودليل تثبيت مختصر.
2. `IntuiForge-Engine-1.0.0-Agent-Migration-and-Updates.zip` — نفس ملف المحرك، بالإضافة إلى تسليم تنفيذي صارم بالعربية للوكيل ودليل تحديثات GitHub.

المستودع الرسمي: https://github.com/Abdulrahman3M/IntuiForge (خاص، يتطلب تسجيل الدخول وصلاحية قراءة). لا توجد حزمة منشورة على npm.

يجب على الوكيل فحص تعليمات المشروع المستهدف وموضع التثبيت، تثبيت IntuiForge وربطه والتحقق منه مع إبقاء RichViz القديم. لا يُزال RichViz من المشروع المستهدف إلا بعد اجتياز بوابة القبول كاملة. لا تحذف طبقة التوافق RichViz أو مكوناتها المرخصة داخل المحرك الجديد.
