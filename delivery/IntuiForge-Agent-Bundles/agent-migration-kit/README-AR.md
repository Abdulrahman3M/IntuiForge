# IntuiForge Engine 1.0.0 — حزمة التثبيت دون اتصال

هذه الحزمة تحتوي محرك IntuiForge القابل للتثبيت محليًا، وملفات التحقق والتراخيص. لا تتطلب تنزيل الحزمة من npm.

## المحتويات
- `intuiforge-engine-1.0.0.tgz` — حزمة المحرك، 518 ملفًا.
- `release-manifest.json` و`SHA256SUMS.txt` — الإصدار والبصمة للتحقق من سلامة الملف.
- `LICENSE`, `NOTICE`, `THIRD-PARTY-NOTICES.md`, `LICENSES/` — التراخيص والإشعارات.

## تثبيت أولي
من مجلد المشروع المستهدف، بعد فحص إرشادات المشروع ومدير الحزم:

```powershell
Get-FileHash .\intuiforge-engine-1.0.0.tgz -Algorithm SHA256
npm install .\intuiforge-engine-1.0.0.tgz
```

يجب أن تطابق البصمة `a174191e76f1b7838aa6a9f8a8ed14308f0f3ae906ab8a80b1a983fa69170a46`.

**لا تحذف RichViz من المشروع المستهدف وقت التثبيت الأول.** أبقه حتى يثبت الوكيل نجاح تثبيت IntuiForge، وربطه الفعلي بصفحة أو مسار في المشروع، واجتياز البناء والفحوصات المطلوبة. اتبع `AGENT-HANDOFF-AR.md` في حزمة الترحيل.

## مستودع المصدر والتحديثات
المستودع الرسمي: https://github.com/Abdulrahman3M/IntuiForge (خاص). يلزم أن يكون الوكيل أو المستخدم مسجل الدخول إلى GitHub وله صلاحية قراءة المستودع كي يسحب تحديثاته. لا يوجد نشر عام على npm.

قبل تحديث لاحق: اسحب `main`، اقرأ `release/release-manifest.json` و`release/SHA256SUMS.txt`، طابق البصمة، راجع تغير الإصدار، وثبّت ملف `.tgz` المطابق. لا تستبدل الحزمة بتغيير ملف دون تحديث القفل والتحقق من البناء. احتفظ بالحزمة السابقة والقفل للرجوع.

راجع `THIRD-PARTY-NOTICES.md`: ترخيص Apache-2.0 يغطي مواد IntuiForge المؤلفة للمشروع فقط؛ المكونات المضمّنة تحتفظ بتراخيصها الأصلية.
