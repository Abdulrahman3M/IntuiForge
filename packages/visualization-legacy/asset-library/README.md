# RichViz Visual Asset Library

This directory contains unchanged copies of the `Assets/` catalog and its referenced gallery media from the user-provided RichViz v0.5.0 archive. They are kept outside `vendor/RichViz-main` so the preserved upstream implementation remains untouched. The visual browser derives asset cards and previews from `Assets/catalog.json` rather than maintaining a second inventory.

The catalog separates 23 Apache-2.0 project illustrations/stickers from 231 Captiva application icons under GPL-3.0+. The Captiva files are redistributed unchanged and retain their upstream `LICENSE`, `README.md`, attribution, source URLs and per-file SHA-256 records. Review the applicable license before redistributing or combining the Captiva collection with another package.
